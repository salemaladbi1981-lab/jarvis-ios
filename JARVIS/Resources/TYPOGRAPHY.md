# JARVIS — Typography Lock

## Arabic UI
- Primary: **IBM Plex Sans Arabic** (weights 400 / 700)
- Used for: navigation, cards, labels, controls, body, statuses
- Fallback: Segoe UI, system-ui, sans-serif
- Bundling: base64 in HTML (offline)
- No second Arabic font.

## Arabic Display Title
- Same IBM Plex Sans Arabic, controlled weight/size
- «جارفس» + major headings

## English JARVIS Display
- Final family: **Cormorant Garamond**
- Weight: **600** (Semibold)
- Style: UPPERCASE, letter-spacing 3–8px, high-contrast serif
- Bundling: **base64 (offline)** — no web-font dependency
- Fallback order: Cormorant Garamond → Georgia → serif
- Used for: `JARVIS` wordmark (brand logo + core title)

## Numerals
- Western: 0-9
- Tabular for: time, temperature, percentages, progress
