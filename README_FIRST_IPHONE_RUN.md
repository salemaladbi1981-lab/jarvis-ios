# تشغيل جارفس على iPhone لأول مرة

## الملف الذي تفتحه في Xcode

افتح هذا الملف فقط:

```
JARVIS.xcodeproj
```

(لا يوجد ملف `.xcworkspace` — المشروع من نوع `.xcodeproj` فقط.)

## الخطوات

1. افتح Xcode (الإصدار 27 أو أحدث).
2. من File → Open، اختر ملف `JARVIS.xcodeproj`.
3. اضغط على مشروع JARVIS (أعلى اليسار).
4. في تبويب Signing & Capabilities:
   - فعّل Automatically manage signing.
   - اختر Team: فريقك الشخصي (Personal Team).
5. غيّر Bundle Identifier إذا احتجت (الحالي: `com.salemai.jarvis`).
   مثال: أضف اسمك ليكون `com.<اسمك>.jarvis`.
6. وصّل iPhone بالكابل. اختر جهازك من قائمة الأجهزة (أعلى الشاشة).
7. اضغط Run (▶).

## أول تشغيل

- وافق على صلاحية التقويم، التذكيرات، والميكروفون لما يطلبها.
- إذا لم توافق على أي صلاحية، التطبيق يستمر بالعمل (يعرض "غير متاح" بشكل منظم).

## ملاحظة

الصوت الحي (المحادثة الصوتية) يحتاج مفتاح على السيرفر لاحقاً.
بدونه تفتح الواجهة طبيعياً وتظهر "الصوت غير متاح" — لا تعطل.
