# JARVIS — Owner Installation Checklist (مرة وحدة، الحد الأدنى)

## توزيع التطبيق (iPhone/iPad)
1. فعّل اشتراك Apple Developer Program (إذا ما عندك — مدفوع، ضروري لـ TestFlight).
2. أنشئ App Record في App Store Connect للـ bundle id `com.salemai.jarvis`.
3. فعّل TestFlight (Internal Testing).
4. أرسل build (أنا أجهّز الأرشيف والـ export، وأنت ترفعه أو أؤتمت الرفع).

## التثبيت (iPhone/iPad)
5. استلم دعوة/رابط TestFlight.
6. ثبّت TestFlight (إذا ما هو مثبت).
7. ثبّت JARVIS.
8. افتحه ووافق على الصلاحيات (تقويم/تذكيرات/ميكروفون).

## جلسة التحقق الموحدة (بعد التثبيت)
9. «وش عندي اليوم؟» — يقرأ تقويمك.
10. «وش عندي من تذكيرات؟» — يقرأ تذكيراتك.
11. (لاحقاً) محادثة صوتية + مقاطعة.

## macOS
12. أنا أجهّز نسخة موقّعة/notarized، وأنت تثبّتها من DMG (لا Xcode يدوي).

## ملاحظة
هذي كل الخطوات الحقيقية اللي عليك. الباقي كله أؤتمته أنا.
