# JARVIS — M3.4 Real Runtime Owner Checklist (مرة وحدة، دقايق)

الهدف: إثبات قراءة حقيقية (غير mock) من تقويم Apple والتذكيرات بصلاحيتك.

## قبل البدء
- جهاز iPhone/iPad/Mac فيه حساب Apple + تقويم/تذكيرات.
- التطبيق (JARVIS) مبني من الـ repo على GitHub.

## الخطوات الست (بس هذي)

1. **افتح التطبيق** على iPhone (أو Mac) — شغّل آخر build.
2. **وافق على صلاحية التقويم** لما يطلب (Calendar).
3. **وافق على صلاحية التذكيرات** لما يطلب (Reminders).
4. **أنشئ إدخالين اختبار** (يدوياً في تطبيق التقويم/التذكيرات):
   - حدث تقويم اسمه: `JARVIS Runtime Test` (وقت اليوم).
   - تذكير اسمه: `JARVIS Reminder Test` (اليوم).
5. **اسأل جارفس** (في التطبيق):
   - «وش عندي اليوم؟» — المفروض يرجع `JARVIS Runtime Test`.
   - «وش عندي من تذكيرات؟» — المفروض يرجع `JARVIS Reminder Test`.
6. **أرسل لي**: هل ظهر الحدثان؟ (نعم/لا) + أي لقطة شاشة آمنة (بدون بيانات شخصية أخرى).

## خلاص
هذا كل اللي أحتاجه منك. أنا أأتمت كل الباقي (الكود، الـ provider، الـ routing، الـ tests، الـ audit).

## ملاحظة خصوصية
لا تصوّر أحداث/تذكيرات شخصية أخرى. فقط إدخالا الاختبار، أو احجب الباقي.
